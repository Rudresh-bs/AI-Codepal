## ✨ Features

- 🤖 **Powered by Gemini 2.5 Flash** — Fast, capable, and free via Google AI Studio
- 🎯 **5 Coding Modes** — General Assistant, Code Reviewer, Bug Fixer, Code Explainer, Algorithm Helper
- 🌐 **Multi-language support** — Python, JavaScript, Java, C++, SQL, React, and more
- 🎨 **3 Response styles** — Detailed with explanation, Code only, or Concise
- 💬 **Full conversation memory** — context preserved across the session
- 🖤 **Dark terminal UI** — Space Mono + Syne fonts, green accent theme
- ⚡ **No backend required** — runs entirely in Streamlit, API key entered in sidebar

---

## 🎯 Coding Modes

| Mode | What it does |
|------|-------------|
| 🧑‍💻 General Assistant | Write, explain, and improve code |
| 🔍 Code Reviewer | Review for bugs, performance, and best practices |
| 🐛 Bug Fixer | Find and fix errors with clear explanations |
| 📖 Code Explainer | Break down code line by line in simple terms |
| 🧠 Algorithm Helper | Solve DSA problems and analyze complexity |

## 🔑 API Key Setup

1. Go to [aistudio.google.com](https://aistudio.google.com)
2. Sign in with your Google account
3. Click **"Get API Key"** → **"Create API key"**
4. Copy the key and paste it into the sidebar of the app

> The key is never stored — it lives only in your browser session.
